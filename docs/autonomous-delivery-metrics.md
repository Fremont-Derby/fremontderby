# Autonomous delivery metrics (#251)

Measure delivery by **customer outcomes**, not agent activity volume.

## Primary outcomes
- Season 1 pilot path completable: register → roster → lineup → score → finalize
- Time-to-fix for P0 defects after discovery
- Open P0 count trend
- Successful production deploys with green health

## Rework signals
- Issues reopened within 7 days
- PRs reverted
- Repeat infra tickets (DNS/auth/deploy)

## Agent activity (secondary only)
- Issues closed / PRs merged — never the success metric alone
